# تشغيل واختبار PWA الأساسية

## الحالة المنفذة

- Manifest عربي وRTL باسم CARLED.
- أيقونة واحدة بصيغة SVG النصية القابلة للتحجيم؛ لا توجد أيقونات PNG ثنائية.
- تشغيل `standalone` عند دعم التثبيت من المتصفح.
- Service Worker يخزن Offline shell والملفات العامة الثابتة فقط.
- صفحات ومسارات المالك والمحاسب والإدارة وAPI لا تدخل Runtime Cache.
- العمليات POST وPUT وPATCH وDELETE لا تعترض ولا تؤجل عند انقطاع الإنترنت.
- App Context محمي بجلسة المالك أو المحاسب، واستجابته `private, no-store`.
- `X-Request-ID` جديد لكل طلب لتتبع الأخطاء.
- لوحة مشتركة تعرض زر التثبيت عندما يتيحه المتصفح، وتنبه للانقطاع وعودة الاتصال.
- تحديث Service Worker لا يطبق تلقائيًا؛ يطلب من المستخدم حفظ النموذج ثم الضغط
  على «تحديث الآن» قبل إعادة تحميل الصفحة.

## التشغيل المحلي

```bash
npm install
npm run build
php artisan serve
```

افتح `http://localhost:8000` ثم DevTools → Application وافحص Manifest وService
Workers وCache Storage. بعد أول زيارة متصلة، اقطع الشبكة وافتح مسارًا جديدًا؛
يجب أن تظهر صفحة Offline العامة دون بيانات حساب محفوظة.

## فحص العقد

```bash
npm run test:pwa
```

يفشل الفحص إذا عادت أيقونتا PNG القديمتان، أو غابت أيقونة SVG، أو حاول Service
Worker تخزين مسارات التطبيق الخاصة، أو غاب ربط Manifest من القوالب الأساسية.

## ما يحدث عند انقطاع الإنترنت

- التنقل الذي يحتاج Laravel يعرض Offline shell العامة.
- لا يعرض Service Worker نسخة مخزنة من لوحة مالك أو محاسب.
- لا يرسل أو يؤجل بيعًا أو جردًا أو نقلًا أو تحصيلًا.
- لا يدعي نجاح عملية لم تصل إلى الخادم.
- مسودة الجرد المحلية الحالية مستقلة، ولا تصبح معتمدة بسبب PWA.

## ما يحدث عند عودة الإنترنت

- زر إعادة المحاولة يعيد تحميل الصفحة من Laravel.
- لا توجد مزامنة مالية تلقائية أو Outbox في هذه المرحلة.
- يستأنف API الإشعارات الجلب ضمن الجلسة الحالية.
- أي مزامنة مستقبلية تحتاج Idempotency Key وحل تعارض معتمد لكل نظام.

## التثبيت والتحديث

- لا يظهر زر التثبيت إلا بعد إطلاق المتصفح لحدث `beforeinstallprompt`.
- إخفاء رسالة التثبيت يستمر للجلسة الحالية فقط، ولا يمنع المتصفح من عرضها لاحقًا.
- عند اكتشاف نسخة جديدة يظهر تنبيه «تحديث جديد متاح» بدل تحديث الصفحة سرًا.
- لا يرسل التطبيق `SKIP_WAITING` إلا بعد ضغط المستخدم على «تحديث الآن».
- عند انقطاع الشبكة تظهر حالة واضحة تؤكد أن العمليات لم تُرسل، وعند عودتها تظهر
  رسالة مؤقتة ثم يمكن إعادة فتح الصفحة من Laravel.

## التحقق على الاستضافة

بيئة الاختبار الحالية هي `https://carled.ddns.net/`. بعد نشر الملفات وبنائها نفذ:

```bash
npm run test:pwa:deployment -- https://carled.ddns.net
curl.exe -I https://carled.ddns.net/manifest.webmanifest
curl.exe -I https://carled.ddns.net/sw.js
curl.exe -I https://carled.ddns.net/offline.html
```

الفحص الأول يجري اتصال HTTPS حقيقيًا ويتحقق من الحالة وContent-Type وManifest
وأيقونة SVG وسياسة Cache الخاصة بـService Worker. فشل الشهادة أو السلسلة أو اسم
النطاق يؤدي إلى فشل طلب Node بدل تجاوز الخطأ.

المتطلبات:

- HTTPS صالح، باستثناء localhost في التطوير.
- جذر الويب يشير إلى `public`.
- `sw.js` متاح من جذر النطاق.
- ملف `.env` على جهاز XAMPP يحتوي `APP_URL=https://carled.ddns.net` و
  `SESSION_SECURE_COOKIE=true`، مع بقاء `SESSION_DOMAIN=null` للحصول على Cookie
  مقيدة بالمضيف ما لم توجد حاجة موثقة لمشاركتها مع نطاق فرعي.
- لا تقدم CDN نسخة قديمة طويلة العمر من `sw.js` أو Manifest.
- بعد النشر نفذ `npm run build` ثم اختبر التثبيت والانقطاع على جهاز Android حقيقي.

إذا كان HTTPS ينتهي في Reverse Proxy قبل Apache، تأكد أن Laravel يستقبل معلومات
البروتوكول الآمن من Proxy موثوق؛ لا تثق بجميع Proxies دون حصرها. وبعد تعديل `.env`
نفذ `php artisan optimize:clear` قبل إعادة الاختبار.

## حدود المرحلة

- يعتمد توفر زر التثبيت المخصص على دعم المتصفح لحدث التثبيت.
- تستخدم مسودة جرد المحاسب IndexedDB محليًا لمدة أقصاها 30 يومًا، مع فصل المفتاح
  بحسب المحاسب والجلسة والتحقق من إصدار الخادم.
- لا توجد مزامنة Background Sync أو إرسال تلقائي للمسودة؛ زر الحفظ مع الإنترنت
  هو الطريق الوحيد لتثبيت الكميات في Laravel.
- لا توجد مصادقة Token لتطبيق Flutter.
- لا يوجد OneSignal Web SDK أو طلب إذن Push ضمن تأسيس PWA الحالي.
- الأيقونة SVG مقصودة لمنع إدخال ملفات ثنائية إلى حزمة Git الحالية.
