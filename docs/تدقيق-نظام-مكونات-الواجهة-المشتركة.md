# تدقيق نظام مكونات الواجهة المشتركة

> حالة التنفيذ: طُبقت إصلاحات زر التحذير ونافذة المساعدة المشتركة.

## النطاق

- `x-ui.button`
- `x-ui.card`
- `x-ui.badge`
- `x-ui.help`
- لم يتضمن العمل تعديل محتوى الصفحات التي تستخدم هذه المكونات أو شروطها أو بياناتها.

## النتائج

- مكونات البطاقة والشارة تستخدم كلاسات الهوية المركزية ولا تحتوي CSS أو JavaScript مضمّنًا.
- مكوّن الزر يحافظ على نوع `button` افتراضيًا، ويدعم الروابط والأدوار الأساسية.
- مكوّن المساعدة هو الجزء التفاعلي الوحيد، ويعتمد Alpine الموجود في مدخل التطبيق بدل سكربت مستقل.

## التحسينات المعتمدة

- إضافة دور `warning` إلى `x-ui.button` باستخدام `ui-btn-warning` الموجود مسبقًا، دون إضافة لون أو CSS جديد.
- توسيط عنوان ومحتوى نافذة المساعدة أفقيًا.
- إبقاء نافذة المساعدة في منتصف الشاشة، مع ارتفاع أقصى وتمرير رأسي للمحتوى الطويل على الهاتف.
- إغلاق نافذة المساعدة بزر الإغلاق، أو بالنقر على الخلفية، أو بمفتاح Escape.
- إضافة `role="dialog"` و`aria-modal="true"` وتسمية النافذة بعنوان المساعدة.

## حدود الأمان

- لم تتغير خصائص `title` أو `body` أو `variant` الحالية.
- بقي الدور الافتراضي للمساعدة `info` والدور الافتراضي للزر `primary`.
- لم تُضف أي مكتبة أو ملف JavaScript أو كلاس CSS جديد.
