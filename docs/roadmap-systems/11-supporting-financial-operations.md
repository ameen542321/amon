# متابعة المصروفات والاستهلاك الداخلي والعمليات المساندة

## النطاق المنجز

- قراءة المصروفات وتفاصيلها حسب المتجر والفترة المحاسبية.
- قراءة عمليات الاستهلاك الداخلي وبنود كل عملية من اللقطات التاريخية.
- قراءة مشتريات المالك للمالك فقط.
- ملخص أعداد وإجماليات المصروفات والاستهلاك الداخلي ومشتريات المالك.
- Cursor Pagination بحد أقصى 100 سجل وفترة افتراضية 30 يومًا وحد أقصى 367 يومًا.
- استخدام `business_date` مع رجوع إلى `created_at` للسجلات القديمة.

## خارج النطاق عمدًا

- إنشاء أو تعديل أو حذف مصروف أو استهلاك أو عملية شراء.
- استرجاع المخزون أو اعتماد أي أثر مالي من الهاتف.
- تخزين العمليات أو التقارير المالية Offline.
- تعديل معادلات التكلفة أو الإجماليات القائمة.

## عقد API

جميع المسارات تتطلب Bearer token وصلاحية `operations:read` ومعامل `store_id`:

- `GET /api/v1/operations/summary`
- `GET /api/v1/operations/expenses`
- `GET /api/v1/operations/expenses/{expense}`
- `GET /api/v1/operations/internal-use`
- `GET /api/v1/operations/internal-use/{sale}`
- `GET /api/v1/operations/owner-purchases` للمالك فقط

تقبل القوائم والملخص `start_date` و`end_date`. تقبل القوائم كذلك `limit` و`cursor`.

## العزل والخصوصية

- يمر كل متجر عبر `ApiStoreScopeService`.
- كل استعلام يقيد السجلات صراحةً باستخدام `store_id`.
- مشتريات المالك وتكاليفها غير متاحة للمحاسب.
- لا تعرض استجابات الاستهلاك `cost_price` أو `profit` أو الملاحظات الداخلية.
- لا توجد مسارات كتابة تحت `/api/v1/operations`.

## التاريخ والمصدر

- المصروفات والاستهلاك يستخدمان نطاقات التاريخ المحاسبي المشتركة.
- مشتريات المالك تستخدم `business_date`، مع fallback موثق إلى `created_at` للبيانات القديمة فقط.
- ملخص الاستهلاك يقرأ الإجمالي المحفوظ ولا يعيد حساب تكلفة المنتج الحالية.

## Offline

جميع المسارات Network Only ولا تدخل Service Worker cache. لا توجد Outbox أو إعادة إرسال لعملية مالية في هذه المرحلة.

## النشر والرجوع

الإضافة للقراءة فقط ولا تحتوي Migration. الرجوع يكون بإزالة المسارات والقدرة والأعلام من إعداد التطبيق، دون تحويل بيانات.

## التحقق

```bash
npm run test:mobile-operations
php artisan route:list --path=api/v1/operations
```

## قرار المرحلة

أساس القراءة والتدقيق جاهز للمراجعة. الكتابة والاعتماد المالي مؤجلان حتى اعتماد خدمات معاملات مشتركة واختبارات Feature على قاعدة بيانات فعلية.
