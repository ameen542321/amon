# متابعة نظام التقارير وPDF

## النطاق المنجز

- سجل تقارير يعلن النوع، مصدر التاريخ، وتوفر المعاينة وPDF حسب الدور.
- ملخص شهري للمالك يعيد مجموعة محدودة من المقاييس من `MonthlyStoreReportService` المرجعية.
- إنشاء روابط PDF موقعة ومؤقتة للتقرير الشهري وتقرير النقل المخزني.
- إعادة استخدام خدمات وتقارير Blade/PDF الحالية دون نسخ المعادلات إلى API Controller.
- فترة تقرير النقل محدودة بحد أقصى 367 يومًا.

## مصادر الأرقام والتاريخ

- التقرير الشهري مصدره `MonthlyStoreReportService` ويعتمد فترة الشهر ويوم العمل داخل الخدمة.
- تقرير النقل مصدره `StoreTransferReportService` ويعتمد تاريخ الطلب للصادر وتاريخ الإجراء للوارد.
- لا يعيد API حساب التكلفة أو الربح أو المخزون؛ يختار فقط حقولًا من نتيجة الخدمة المرجعية.

## عقد API

- `GET /api/v1/reports?store_id=...`: سجل التقارير.
- `GET /api/v1/reports/monthly/summary?store_id=...&month=YYYY-MM`: معاينة شهرية للمالك.
- `POST /api/v1/reports/downloads`: إنشاء رابط مؤقت، ويتطلب `Idempotency-Key`.
- `GET /api/v1/report-downloads/{type}`: تنزيل موقع زمنيًا؛ لا يقبل معاملات غير موقعة.

يدعم التنزيل النوعين `monthly` و`store-transfers`. عمر الرابط الافتراضي 10 دقائق ومحدود برمجيًا بين دقيقة و60 دقيقة.

## الأمن والخصوصية

- إنشاء الرابط والمعاينة المالية متاحان للمالك فقط.
- يرتبط التوقيع بنوع التقرير والمتجر والمالك والفلاتر ووقت الانتهاء.
- يعاد التحقق عند التنزيل من أن المتجر نشط وتابع للمالك الموجود داخل الرابط الموقع.
- استجابات API تحمل `private, no-store`، والتقارير غير متاحة في Offline cache.
- لا يوضع Bearer token داخل رابط التنزيل.

## التقارير الثقيلة

لم يضف Queue وهمي قبل قياس زمن وحجم التقارير. إذا أثبتت القياسات تجاوز حدود الطلب المتزامن، تنقل عملية الإنشاء إلى Job مع سجل حالة وملف خاص منتهي الصلاحية.

## النشر والرجوع

لا توجد Migration. يمكن تعطيل إنشاء الروابط عبر feature flag ثم إزالة المسارات والقدرة دون تغيير بيانات التقارير.

## التحقق

```bash
npm run test:mobile-reports
php artisan route:list --path=api/v1/reports
```

## قرار المرحلة

أساس السجل والمعاينة والتنزيل الآمن جاهز للمراجعة. تبقى بوابة قياس الأداء الفعلية واختبار PDF على Staging قبل إعلان الإغلاق التشغيلي الكامل.
