# تدقيق نظامي ترقيم الصفحات وبريد استعادة كلمة المرور

## النطاق

- قوالب Laravel المنشورة داخل `resources/views/vendor/pagination`.
- قالب بريد استعادة كلمة المرور `resources/views/emails/reset.blade.php`.
- لم يتضمن العمل أي تعديل على الاستعلامات أو أرقام الصفحات أو رمز الاستعادة أو آلية إرسال البريد.

## نظام ترقيم الصفحات

### ما كان قائمًا

- تسعة قوالب متوازية تحمل هياكل Bootstrap وSemantic UI وTailwind مختلفة.
- اختلاف في النصوص وإتاحة قارئ الشاشة والسلوك المتجاوب بين القوالب.
- تكرار كبير لمنطق العرض نفسه، مع اعتماد بعض القوالب على كلاسات مكتبات غير محملة في التطبيق.

### ما تم اعتماده

- `tailwind.blade.php` هو قالب العرض الكامل الوحيد.
- `simple-tailwind.blade.php` هو قالب العرض المبسط الوحيد.
- قوالب Bootstrap وSemantic UI وDefault أصبحت مداخل توافق تستدعي أحد القالبين المركزيين، لذلك تبقى أسماء Laravel المعتادة صالحة دون تكرار الواجهة.
- أضيفت تسمية عربية للتنقل وحالات `aria-current` و`aria-disabled` وروابط `prev` و`next`.
- أرقام الصفحات تلتف إلى صف مستقل عند ضيق العرض، وتبقى أزرار السابق والتالي قابلة للمس.

## بريد استعادة كلمة المرور

### ما كان قائمًا

- حاوية بعرض ثابت قد تتجاوز شاشة الهاتف.
- رابط الاستعادة الطويل لا يملك قاعدة واضحة للالتفاف.
- محاذاة المحتوى لم تكن موحدة، والخط الاحتياطي لم يتضمن خط PDF/البريد المعتمد.

### ما تم اعتماده

- حاوية بعرض مرن وحد أقصى `600px` وهوامش آمنة على الهاتف.
- توسيط عنوان البريد والنص والزر مع إبقاء اتجاه المستند عربيًا.
- التفاف رابط الاستعادة الطويل ومنحه اتجاهًا يسارًا إلى يمين لسهولة نسخه.
- اعتماد Cairo أولًا ثم `DejaVu Sans` كبديل متوافق مع مرجع الهوية.

## حدود الأمان

- لم تتغير قيمة `$resetUrl` أو طريقة طباعتها أو وجهة الزر.
- لم يتغير عقد `$paginator` أو `$elements` أو عناوين الصفحات.
- بقي CSS البريد مضمّنًا لأن مرجع الهوية يسمح بذلك لتوافق عملاء البريد.
