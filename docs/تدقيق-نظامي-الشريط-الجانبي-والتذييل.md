# تدقيق نظامي الشريط الجانبي والتذييل

> حالة التنفيذ: طُبق تنظيف الروابط والملفات غير المستخدمة في النظامين.

## الشريط الجانبي

- تبين أن `dashboard.sidebars.user` غير مستدعى من أي View أو Controller؛ التخطيط يستخدم سايدبار المدير فقط، بينما المالك يعتمد شريط التنقل العلوي.
- حُذف الملف غير المستخدم بعد التحقق من عدم وجود مراجع له، وبذلك أزيلت معه استعلامات متاجر كانت تنفذ من Blade دون أن تصل للمستخدم.
- أزيلت من سايدبار المدير مجموعات المتاجر والمحاسبين والتقارير وسجل العمليات لأنها كانت روابط `#` معلقة بلا وجهة.
- بقيت روابط لوحة المدير وفحوص سلامة البيانات والمستخدمين كما هي.
- لم تُعدل كتلة الإشعارات أو روابطها أو قراراتها في هذه الخطوة.
- أضيفت تسمية وصول وحالة `aria-expanded` لزر الطي وقائمة المستخدمين.

## التذييل

- أزيلت روابط الخصوصية والشروط والدعم لأنها كانت روابط `#` غير قابلة للاستخدام.
- أزيل رقم الإصدار الثابت `1.0.0` لأنه غير مرتبط بمصدر إصدار فعلي وقد يعرض معلومة قديمة.
- بقيت حقوق النشر والسنة الديناميكية فقط، في تخطيط متوسط ومتجاوب.

## حدود الأمان

- لم تُضف وجهات أو صلاحيات أو استعلامات بديلة.
- لم تتغير بيانات المستخدم أو المتجر أو الإشعارات.
- لم يُضف CSS أو JavaScript جديد.
