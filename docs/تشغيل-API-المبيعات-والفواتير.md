# تشغيل API المبيعات والفواتير

API قراءة فقط يتطلب `sales:read` و`store_id` مصرحًا:

- `GET /api/v1/sales`: قائمة Cursor مع فلاتر يوم العمل، النوع، ووجود الفاتورة.
- `GET /api/v1/sales/{id}`: تفاصيل البيع وبنوده وملخص الفاتورة.
- `GET /api/v1/sales/summary`: إجمالي يوم العمل والكاش والشبكة والمتبقي.

تعاد المبالغ كنصوص عشرية، وتستخدم البنود لقطات الاسم والوحدة والسعر وقت البيع.
لا يعيد API الربح أو تكلفة المنتج أو تكلفة البند، ولا يوفر إنشاء بيع أو تحصيل أو
إلغاء. `business_date` هو مرجع التقارير و`created_at` وقت تقني.

## النشر والقبول

```bash
php artisan migrate
php artisan optimize:clear
npm run test:mobile-sales
```

اختبر كاش وشبكة ومختلط وآجل جزئي، بيعًا بطقم ورول، وفاتورة، ثم طابق الملخص مع
تقرير يوم العمل. Refresh للجلسات القديمة يمنح `sales:read`. الفهارس توسعية ويمكن
إبقاؤها عند تعطيل المسارات.
