# تشغيل API الشفت ويوم العمل

هذه المرحلة قراءة فقط، معزولة حسب المتجر، وتتطلب `shifts:read`:

- `GET /api/v1/shifts/current`: يوم العمل، رقم الشفت، بداية النافذة، والحد الأقصى.
- `GET /api/v1/shifts/history`: الإقفالات السابقة وموازنة الكاش مع Cursor.
- `GET /api/v1/shifts/gaps`: أيام العمل الناقصة والأيام المفتوحة المتاحة.

يعتمد API خدمة `ShiftLifecycleService` نفسها المستخدمة في الويب، ولا يعيد اشتقاق يوم
العمل من تاريخ الخادم. في طلب Bearer بلا Web Session يتجاهل سياق معالجة الفجوة
المخزن في Session بدل محاولة قراءته.

سجل الإقفال يعيد القيم المالية كنصوص عشرية، ويفرق بين `business_date` ووقت
`start_time/end_time`. لا يوفر API فتح أو إغلاق أو تصحيح شفت، ولا يغير الموازنة.

## النشر

```bash
php artisan migrate
php artisan optimize:clear
npm run test:mobile-shifts
```

اختبر متجرًا بشفت واحد وآخر بعدة شفتات، يومًا ناقصًا، وإقفالًا بفرق موجب وسالب.
قارن النتيجة مع لوحة المحاسب قبل الاعتماد. الفهارس توسعية ويمكن إبقاؤها عند تعطيل
المسارات.
