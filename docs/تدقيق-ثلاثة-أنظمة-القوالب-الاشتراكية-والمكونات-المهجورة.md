# تدقيق ثلاثة أنظمة: قوالب الاشتراكات التجريبية والمكونات المهجورة

> حالة التنفيذ: حُذفت الملفات غير المرتبطة بعد التحقق الساكن من Controllers والمسارات والواجهات.

## 1. قوالب الاشتراكات التجريبية

### الملفات المحذوفة

- `resources/views/subscriptions/assign.blade.php`
- `resources/views/subscriptions/manage.blade.php`
- `resources/views/subscriptions/plans.blade.php`
- `resources/views/subscriptions/show.blade.php`
- `resources/views/admin/subscriptions/index.blade.php`

### سبب الحذف

- لا يعيد أي Controller حالي هذه القوالب، ولا توجد مسارات معرفة لأسماء `subscriptions.*` أو `admin.subscriptions.*` التي تستعملها.
- احتوت صفحات الإسناد والإدارة على مستخدمين وأسعار وتواريخ مكتوبة يدويًا بوصفها أمثلة مؤقتة.
- صفحة الإدارة كانت تمتد من `layouts.app` غير الموجود في المشروع الحالي.
- النظام الفعلي المحفوظ دون تغيير هو `SubscriptionController` مع صفحات `expired`, `renew`, و`history`.

## 2. مكوّن أيقونة عمليات المحاسب

### الملف المحذوف

- `resources/views/accountants/partials/op-icon.blade.php`

### سبب الحذف

- لا يوجد `@include` أو View أو Controller أو مكوّن يستدعي هذا الجزء.
- كان يحتفظ بخريطة حالات وأيقونات كبيرة لا تصل إلى أي واجهة فعلية.
- لم تُحذف أو تُعدل أيقونة مستخدمة داخل صفحات عمليات المحاسب الحالية.

## 3. مكوّن قسم المتجر القديم

### الملف المحذوف

- `resources/views/components/store-section.blade.php`

### سبب الحذف

- لا يوجد أي استعمال لـ`x-store-section` في المشروع.
- كان يبني رابط إضافة مع `return_to` داخل المكوّن، لكن صفحات المتجر الحالية تستخدم هياكلها ومكوناتها الفعلية ولا تمر عبره.
- لم تتغير مسارات المتاجر أو معاملات `return_to` في أي واجهة مستخدمة.

## حدود الأمان

- لم يُعدل Controller أو Route أو Model أو Migration أو استعلام.
- لم تتغير أسعار الاشتراكات أو مددها أو طريقة التجديد أو الكتابة في قاعدة البيانات.
- لم تتغير عمليات المحاسب أو المتاجر أو صلاحياتها.
- الحذف يقتصر على Views غير مستدعاة، وتحمي عقود الفحص عدم عودة بياناتها التجريبية.
